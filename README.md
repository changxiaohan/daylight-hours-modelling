# Daylight Hours Modelling (Python)

Mathematical modelling of **daylight hours** with successive model refinements.

## Features
- Initial simple model for daylight hours as a function of time/latitude.
- Iterative improvements (`three model/simple model_improve.py`) trading off accuracy vs. complexity.
- Validation scripts (`test2.py`).

## Skills Demonstrated
Mathematical modelling · model selection & refinement · numerical implementation in Python.
